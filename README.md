# Projet Asteroids

## Description
L’objectif de ce projet est de créer un jeu inspiré du célèbre jeu **Asteroids** paru en 1979.  
👉 [En savoir plus sur Asteroids](https://fr.wikipedia.org/wiki/Asteroids)

Le joueur contrôle un vaisseau spatial dans un univers rempli d'astéroïdes qu’il doit éviter ou détruire. Ce projet met en œuvre des concepts de base en programmation, comme :
- Les animations.
- Les collisions.
- La gestion des entrées clavier.
